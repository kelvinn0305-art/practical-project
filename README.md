# 📊 Customer Shopping Behavior Analysis (Excel Project)

## 📌 Project Overview

This project analyzes customer shopping behavior using Excel. The dataset includes customer details, purchase patterns, payment methods, and discount usage. The goal is to extract meaningful insights using data cleaning, Pivot Tables, and dashboard visualization.

---

## 📁 Dataset Information

The dataset contains the following columns:

* Customer ID
* Age
* Gender
* Item Purchased
* Category
* Purchase Amount
* Location
* Size
* Color
* Season
* Review Rating
* Subscription Status
* Shipping Type
* Discount Applied
* Previous Purchases
* Payment Method
* Frequency of Purchases

---

## 🧹 Data Cleaning Steps

* Removed duplicate records
* Handled missing values (replaced with 0 / "Unknown")
* Removed extra spaces using TRIM
* Standardized text format (Proper Case)
* Corrected data types (Number, Currency, Percentage)
* Verified consistency in values (e.g., Gender, Location)

---

## 🔄 Data Transformation

* Converted Purchase Amount to Currency format
* Converted Discount Applied to Percentage
* Created new calculated fields:

  * Final Amount after discount
  * Customer Type (using IF condition)
  * Age Group (Young, Adult, Senior)

---

## 📊 Data Analysis (Pivot Tables)

The following Pivot Tables were created:

1. Category-wise Sales
2. Location-wise Sales
3. Payment Method Analysis
4. Season-wise Sales
5. Gender-wise Spending
6. Discount Impact on Sales

* Location-wise Sales (Column Chart)

* Season-wise Sales (Line Chart)
* Gender-wise Spending (Bar Chart)
* Discount Impact (Column Chart)

---

## 🔍 Key Insights

* Electronics is the top-performing category
* Certain locations generate higher sales
* Credit Card is the most used payment method
* Summer season shows highest sales trend
* Discounts (10–20%) increase purchase behavior
* Female customers show higher spending in some categories
